# ADR 0025: Human-only assessment acceptance

## Status

Accepted

## Decision

Acceptance is explicit per normalized item and creates only a Workflow
recommendation draft with assessment provenance. Workflow rechecks tenant,
active instance, state, and aggregate version. Acceptance never submits a
recommendation or final decision.

## Consequences

AI remains advisory. Phase 4 eligibility, four-eyes, recommendation, and final
approval controls retain authority.
